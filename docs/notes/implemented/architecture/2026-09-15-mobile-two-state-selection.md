# Agent Note: Android 两态选择模型（浏览态圆点 + 选中态头部变形/底部动作条，取代行级 `…` 抽屉）

Status: implemented

## Problem

[行级 `…` 抽屉批次](2026-09-15-mobile-row-overflow-drawer.md)落地后,用户出示两张百度网盘「文件」页截图(浏览态/多选态各一张)并确认按方案 A 改造:浏览态行尾是一个安静的选择圆点(没有行首常驻复选框、没有每行 `…`);点圆点或长按进入选中态后,顶部标题区整体变形为「取消 / 已选中 N 个 X / 全选」,底部升起动作条承载单行/批量动作——选中 1 个时动作条即该行动作,多个时为批量动作。行 `…` 抽屉模型被整体取代(它把动作藏在"选中行的 `…`"里,发现性与系统惯例都差)。

## Decision

1. **共享 chrome**(`lib/widgets/mobile_selection_chrome.dart`):`MobileSelectionHeader`(取消 | 已选中 N 个 X | 全选/取消全选,文字按钮 primary 色、≥48dp)、`MobileSelectionBottomBar`(图标上标签下的横排动作条,前 4 个平铺、其余进「更多」共享底部抽屉;动作空则不渲染,`busy` 时整条变 spinner)、`MobileRowSelectDot`(浏览态行尾 48dp 命中区的空心圆,复用 `ListSelectionControl(selected: false)`)。
2. **每页两态**:选中态判定 = 过滤后仍可见的选择非空(回收站 `_selectedFilteredCount`、任务 `selectedVisible`、文件管理 `_selectedObjectKeys`/`_selectedTrashItemIds`)。浏览态:行尾圆点、无行首控件;行点击是主操作(文件=打开,任务=展开/收起明细,回收站无主操作→行点击即选中),长按=选中。选中态:行首 48dp 勾选控件接管、行点击切换选中、页面头部变形、底部动作条出现。页面级入口(任务操作/回收站操作/文件 `+`)仅浏览态可见(选中态头部被接管——与百度截图一致)。
3. **桶行 `…` 保留**:桶列表不可选,桶管理动作(打开/桶设置/打开回收站/WebDAV)仍走行尾 `…` 抽屉——两态模型只取代"可选行"的动作承载。
4. **文件管理页内桶回收站**(原点击=恢复、行尾内联图标、死"全选"头)一并接入:新增 `_selectedTrashItemIds` 与批量恢复/彻底删除(逐项 API + 一次 reload,复用单条路径的 request/generation 守卫);trash mutation 发起即退出选中态,避免待重载期间 Back 被选中态吞掉。
5. **任务明细对齐**:浏览态任务行去掉勾选列后,`RemoteTaskDetails` 缩进从 80px 契约值放宽为可传参(浏览态 52px = 12+28+12,选中态/桌面 80px 不变)。
6. **系统 Back**:文件管理页 Back 先清空选择再回退位置(`_consumeMobileSelectionForBack`);回收站/任务 tab 无页面级 Back 钩子,记录为 Known P3。
7. **桶内回收站与全局回收站的批量删除确认**分别沿用 `showDeleteTrashItemsDialog`;动作条标签保持短动词(恢复/彻底删除/取消任务/…),计数只出现在头部「已选中 N 个」。
8. **选中态隐藏底部导航栏**(用户 APK 体验反馈):shell 经 `MobileSelectionActivity` 单例(ChangeNotifier,页面在 build 里按自身选中态 report,值变化经微任务延迟通知避免 build 期内标脏 shell;页面 dispose 撤销报告)在「当前可见 tab 报告选中」时隐藏 `MobileNavigationBar`——IndexedStack 隐藏页的陈旧报告由 shell 与 `_effectiveSelectedItem` 组合消解。动作条随之全宽贴底(移出各页 16dp 边距列),自带底部安全区(容器内 `SafeArea(top:false)`,背景色延伸到手势区)。
9. **动作条两排全量展示、无「更多」**(同批反馈,参照百度截图):≤4 个动作单排,更多则两排均衡分列(5→3+2、6→3+3、7→4+3),文件管理单选最多 7 动作(打开/下载/分享/复制/移动/重命名/删除)全部直接可见;`visibleLimit`/「更多」/`sheetTitle` 参数删除。回收站(2)与任务(≤3)动作数不触两排。
10. **回收站相关页面级入口移除**(次日反馈,"功能已被覆盖"):回收站 tab 右上 `…`(刷新/清空回收站)与文件管理回收站视图入口(返回文件/清空)删除——返回文件=顶栏/系统 Back,清空=全选+彻底删除。文件视图 `+`(新建目录/上传)与任务页入口保留(前者无其他入口,后者队列级语义)。代价:回收站 tab 无手动刷新(IndexedStack 常驻+mutation 自动重载,远端新删除要切桶/重进才出现),记 P3,恢复方向是下拉刷新而非恢复入口。
11. **「详情」成为单选动作条首项**(同反馈,参照百度「文件详情」弹窗):`showMobileDetailSheet`(标签灰字在上、值加粗在下,长路径无 maxLines 换行)展示系统已有元信息——对象:名称/类型/大小/修改时间/完整路径/所属桶;回收站条目:名称/类型/大小/删除时间/原路径/所属桶。纯信息无动作按钮;文件对象与两个回收站表面均接入,单选触发。
12. **回收站页面级入口恢复**(次日裁决,撤销同批第 10 条):回收站 tab 的 刷新/清空 与文件管理回收站视图的 返回文件/清空 回到右上角单一入口——「清空=全选+彻底删除」在多桶场景与确认文案上并不等价,直接入口更顺手。
13. **任务明细改走「详情」动作**(次日反馈):Android 任务行不再行内展开明细,浏览态行点击=进入选中(与回收站一致,任务无浏览态主操作);单选动作条首项「详情」打开任务详情 sheet(操作/状态/所属桶/完整路径/本地路径/阶段或读取范围/依赖/错误)。`RemoteTaskDetails` 行内面板与 80px 缩进契约回到桌面专属,`remoteTaskBrowseContentIndent`(52px)与 `RemoteTaskDetails.indent` 参数随之删除。动态事件记录与物理传输 ID 不进 sheet(P3:仍需桌面面板)。
14. **账号/设置页卡片恢复**(次日反馈,"把框加回来"):撤销无边框批次在这两页的改动——账号块回到 `ShadCard` + 12dp 块距,设置索引分组卡与详情分区 `_buildCard` 回到带边框卡片;无边框基线收敛为列表页(文件/回收站/任务)专属。
15. **Android 选中态行尾误渲染桌面内联图标修复**(用户发现"选中后还有下拉按钮"):第 13 条改行点击时,`_TaskRightSide` 的分支条件仍是「非浏览态=桌面内联图标」,Android 选中态因此渲染了 取消/重试/明细 chevron。修正为按平台分流:Android 选中态行尾只剩状态徽标与 spinner(浏览态圆点),桌面保留内联图标;回归断言选中态行内无 chevronDown/circleX。
16. **「修复后仍见 chevron」确认为旧安装包**(次日用户复报):解包当日 `app-arm64-v8a-release.apk` 的 `libapp.so` AOT 快照取证——两态新字符串「已选中/取消全选/任务详情」在包内,桌面专属「查看明细/收起明细」已被 Android release 构建裁剪,且构建时间晚于修复改动,判定手机上运行的是旧包。同轮用户以 HyperOS 迷你小窗完成极窄宽度实测(通过),窄屏适配闭环;实测途径与复查项记录在 mobile_ui 正典。

## Alternatives considered

- **`…` 与圆点并存**(方案 B)——行尾拥挤,且用户选了方案 A(照百度网盘,圆点替换 `…`,动作全走选中态底栏)。
- **保留行首常驻复选框**——浏览态列表左侧一列空圆,行内容被挤右,与截图的干净浏览态不符。
- **选中态仅高亮行、头部不变**——批量计数与退出入口(取消)没有稳定位置;百度模型的头部变形正是这两者的载体。
- **文件管理桶内回收站维持旧交互**——点击即恢复是误触危险源,且与同一页面对象列表的交互模型分裂;一并改造成本可控(选择集 + 两个批量方法)。
- **Back 在回收站/任务 tab 也先清选择**——需要 shell 为每个 tab 增加页面级 Back 钩子,超出本批范围,记 P3。

## Consequences

- Android 可选行的全部动作都要求先进选中态(多一步);换来的是浏览态行干净、批量动作有常驻可见入口、退出选择有明确按钮。
- 单个对象的写动作(重命名/删除/复制/移动)落在动作条「更多」抽屉(单选最多 预览/下载/分享 + 写动作四项);批量动作(下载/复制/移动/删除)直接平铺或进更多。
- `RemoteTaskOverflow`/行抽屉装配、`GlobalTrashBrowser` 批量参数(`onBatchRestore` 等)、对象行 `_MobileObjectOverflowMenuButton` 及其动作装配全部删除;对应浏览器级测试改写为行契约(圆点/选中态控件/父行与删除中行无圆点),页面级行为由 widget_test 整机用例覆盖(头部变形、全选、取消、详情 sheet、恢复触发与批量彻底删除确认取消)。
- 任务页批处理运行中:选中态若在,底部动作条整条变 spinner(页面入口在选中态不可见)。
- 桌面(含窄窗)零变化:表头、全选、内联图标、`TrashRowActions`、卡片都保留。
